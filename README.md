# VaultX — Prototipo navegable

Prototipo navegable de **VaultX**, una plataforma que centraliza la gestión de cuentas bancarias de distintos bancos con una sola autenticación mediante **GAUDI** (firma digital del BCCR).

**Ver el prototipo:** https://jose0305rm.github.io/vaultx-prototipo/

Proyecto del curso LTI06 — Diseño de la Experiencia de Usuario, Universidad Latina de Costa Rica.
Autores: Jose Pablo Hidalgo Navarro y Jose Alberto Ruiz Mendoza.

## Contenido

21 pantallas organizadas según el árbol de navegación:

- **Acceso:** ingreso únicamente con la firma digital GAUDI
- **Mis cuentas:** ver cuentas, añadir cuenta, bloquear cuenta, gestionar alertas
- **Transacciones:** enviar dinero (SINPE Móvil), mover dinero entre cuentas, gestionar beneficiarios, pagos programados, movimientos, divisas
- **Estadísticas:** gráfico de pagos, distribución de monto por cuenta, pagos por beneficiario, exportar archivo
- **Soporte:** reportar movimiento, consejos anti-estafas, GAUDI, preguntas frecuentes, contacto, seguridad (MFA), reportar error

Cada pantalla tiene su propia dirección (por ejemplo `#Enviar` o `#Estadisticas`), y el menú «Ir a» permite saltar a cualquiera.
